# 🎯 Number Guessing Game

A simple interactive Number Guessing Game built using HTML, CSS, and JavaScript. The game generates a random number between 1 and 10, and challenges users to guess the correct number. It provides feedback for each guess and keeps track of the number of attempts and previously guessed numbers.

## 🌐 Live Demo

[![Live Demo](https://img.shields.io/badge/Live-Demo-orange?style=for-the-badge&logo=github)](https://inthusha20241647-commits.github.io/number-guessing-game/)


## ✨ Features

- 🎲 **Random Number Generation:** Generates a random number between 1 and 10.
- 🔢 **Number Input:** Allows users to enter their guesses.
- ⬆️ **High Guess Feedback:** Informs users when their guess is higher than the generated number.
- ⬇️ **Low Guess Feedback:** Informs users when their guess is lower than the generated number.
- 🏆 **Winning Message:** Displays a winning message when the correct number is guessed.
- 🔢 **Attempt Tracking:** Counts the number of guesses made by the user.
- 📋 **Guess History:** Displays all previously entered guesses.
- 🎨 **Gradient Background:** Uses a colorful gradient background and styled game interface.

## 🛠️ Technologies Used

- CSS3

## 🎮 How to Play

1. Open the game in your browser.
2. Think of a number between 1 and 10.
3. Enter your guess in the input field.
4. Click the **Guess** button.
5. Read the feedback to find out whether your guess is too high or too low.
6. Continue guessing until you find the correct number.
7. Check your total attempts and previous guesses.
