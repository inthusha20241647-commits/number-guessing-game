# 🕹️ number-guessing-game

A simple and interactive Number Guessing Game built with HTML, CSS, and JavaScript

## ✨ Features

- 🎲 Random number generation (1–10)
- 🎯 Instant feedback for guesses
- 🏆 Win message for correct guesses
- 🔢 Tracks guess count and previous guesses
- 🎨 Attractive gradient background and styled UI

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
